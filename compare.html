Each coder clicks Export codes on the coding page, which downloads a file named like ad-codes_Name_date.csv. Upload one coder's file in each box below. Once both are uploaded, the comparison appears automatically.

Your files are never uploaded. This page reads them inside your browser only. It can't save anything to GitHub or any server, and it forgets the files when you close or refresh the tab. Keep your results files on your own computer and don't add them to the repo.

Agreement by dimension

% agree: share of ads where both picked the same option. Cohen's κ: agreement corrected for chance (Cohen 1960). Weighted κ: quadratic-weighted, for ordered scales only. Near-misses (e.g. 3 vs 4) count as partial agreement. Uses only ordered answers, so "Can't tell" etc. are left out; see its n. Rating: Landis & Koch (1977): <0 poor, 0–.20 slight, .21–.40 fair, .41–.60 moderate, .61–.80 substantial, .81–1 almost perfect. "—" = κ can't be computed (e.g. both coders used one option for every ad).
